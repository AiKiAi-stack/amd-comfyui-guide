# RX 6650 XT 本机实测

2026年10月26日，Ubuntu 24.04，RX 6650 XT 8GB。应用运行在Docker容器中，Python 3.12.15、PyTorch 2.12.0、ROCm 7.14、BF16完整官方权重。固定种子1895，每行对应一项测试目的。

| 测试目的 | 输入 | 输出长度 | 合成用时 | 本服务显存峰值 |
| --- | --- | --- | --- | --- |
| 内置音色与GET API | 15字，灵小柔 | 2.8秒 | 13.7秒 | 2932 MiB |
| 参考音频克隆与Gradio API | 16字，官方lingguang参考音频及逐字文字 | 3.2秒 | 11.4秒 | 2922 MiB |
| 网页上传txt、分段与拼接 | 885字，13段，目标分段长度64 | 145.2秒 | 527.1秒 | 2948 MiB |
| 网页音色设计与进度回调 | 16字，描述青年男声 | 3.0秒 | 14.1秒 | 2942 MiB |
| 表演指令与POST JSON API | 16字，要求轻声温柔 | 3.6秒 | 13.1秒 | 2905 MiB |

合成用时不包含首次模型加载。首次内置音色测试加载约13.3秒；重建容器后音色设计测试也重新加载了模型。显存是PyTorch在本服务中统计的已分配峰值，包含模型，不是整张显卡的总使用量；最高2948 MiB约为2.88 GiB。当前完整权重运行没有验证“1G显存可用”。

上述5项均返回可解码、非静音、数值有限的44.1kHz WAV。长文输出的实时因子约3.63，即生成1秒音频平均需要约3.63秒；目前适合等待生成后播放。尚未测五万字连续合成、其他语言、并发或长期稳定性。没有进行逐字转写评分，也没有给声音克隆相似度、描述遵循程度或主观音质打分。

参考音频来自官方仓库`data/voice_presets/voice_audio/lingguang.wav`，其文字为“诶，你今天有空吗？我们能不能聊聊这件事啊？”。测试目标文字为“夜色渐渐深了，愿你今晚睡个好觉。”，与参考文字不同。内置音色测试文字为“你好，欢迎使用本地语音工作台。”。

容器内8项检查通过：输入校验、长文本不截断、txt编码、音频读写、重采样、80维说话人特征、HTTP校验及拒绝任意服务器音频路径。模型主权重、说话人编码器及分词器大文件的SHA256与官方LFS对象一致，见[校验记录](model-origin-check.json)。
