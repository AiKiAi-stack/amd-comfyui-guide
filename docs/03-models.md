# 03 · 模型实测导航

每项功能的最终图片、输入、提示词和结论见 [总报告](../trials/2026-10-19-features/feature-report.md)。这里帮助选择入口，不替代逐项证据。

- **Kroma Q2**：低分辨率文生图可运行；风格参考会复制主体，换头与多参考合成有局限。原参考链内部升到 1024 后 OOM；降低参考编码尺寸后的结果另列。见 [早期测试](../trials/2026-10-18/README.md)。
- **MOSS SFT / 8步 DMD LoRA**：gfx1032 INT8 fallback 与正确时间尺度后可出图。图生图的水彩要求仅部分达到，简单英文文字和布局提示另有独立案例。8步配方是本机候选，不宣称复现作者未公开的完整参数。
- **Qwen Image / Turbo / UN**：文生图、参考编辑、局部重绘、多参考与姿态探索分别记录。CPU 文本/视觉编码、CPU VAE、关闭 prefix cache 是部分案例的稳定性规避。“UN”命名不代表已证明解除限制；姿态参考也不是专用 Pose Control 网络。
- **FLUX.2 Klein**：七项编辑有独立证据。改色、图案迁移、双人合成、删除达到各例主要目标；风格、中文替换及二次编辑仍有偏差。恢复默认锁页内存后成功；禁用锁页内存产生的 API-success 噪声图保留。见 [七项验收](../trials/2026-10-20-flux2-klein/README.md)。
- **Z-Image AIO / GGUF**：AIO 9/8/4步、中文/英文、成年人体艺术探索，以及 GGUF 文生图均有对应输出。GGUF 同进程第二次请求发生访问异常；独立服务重试成功不能称连续运行稳定。见 [完整记录](../trials/2026-10-20-zimage/README.md)。
- **Flux.3**：保留来源选择与未成功/未验证记录，不能拿 FLUX.2 的图片当作其成功证据。具体已运行项目及错误见总报告。

来源分为已核验正文、索引标题、作者站外材料、上游文档和本机实验。早期多数微信文章没有读到全文，因此不是原文整合包的精确复现；Z-Image 两篇离线正文与 FLUX.2 Klein 来源边界在各卡片单列。本仓库不转载文章全文。
