## 优先处理的失败或无输出：5 条记录

1. **Qwen 自动反推提示词并再生成**：`qwen-caption`。GPU INT8 失败，浮点回退后显存不足；没有生成提示词或图片。验收必须同时有与输入相符的文字输出和使用该文字生成的独立图片，不能只验证 TextGenerate 节点注册。
2. **同一功能的 CPU 重试**：`qwen-caption-cpu`。540.84 秒后 CPU 申请 2,489,319,424 字节失败，`text_outputs=[]`、`images=[]`。换到 CPU 没有解决问题。这条原本未出现在 HTML，也没有独立 review，本轮补回失败结论和报告卡片。
3. **Kroma 只取风格、换新主体**：`kroma-style-ref`。目标是版画风格的猫头鹰，实际仍复制参考狐狸及森林，虽然 API success，功能未达到。需独立测试参考条件/强度或适配器，验收主体必须是猫头鹰，不能继续用“保留风格”代替目标。
4. **FLUX.2 Klein 1024² 文生图**：`flux2-klein-t2i-1024`。采样至 3/4 时 native Aborted，栈在 `cast_to_device`，无 PNG。512 成功不覆盖本项；需要在 1024 原尺寸获得完整采样、解码、输出和目视结果。
5. **Z-Image 双 GGUF、CPU 文本编码低显存基线**：`zimage-gguf-photo`。长时间加载、整机可用内存低于 0.5GB 后人工停止，无输出。后来的 GPU 文本编码和本轮 GGUF 连续测试成功，都不是这项 CPU 配置的验收。需先定位 CPU 装载内存与进度，再决定是否保留为可用配置。
