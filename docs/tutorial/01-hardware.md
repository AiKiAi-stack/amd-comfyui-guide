# 01 · 先确认能不能照做

这一章不装任何东西。读完你能判断自己的机器属于哪一档、能不能照做，以及 512×512、768、1024 里哪几个值得试。

答案从卡开始。先查三件事，再决定从哪一章开始。

## 动手检查

1. 架构代号。装好驱动后跑 `rocminfo | grep gfx`，记下打印出来的 gfx 编号。完整做法见 [AMD 显卡适配矩阵](./08-amd-matrix.md)。
2. 显存档位。8 GB、12 GB 到 16 GB、24 GB 及以上，不同档位能试的尺寸不一样。
3. 系统和驱动。Linux 走 ROCm，Windows 走 AMD 的 multi-arch 轮子；两边的安装和排障分开写。

三件事查清楚，再看自己落在哪一档。拿不准也没关系，下面这张表同样能用来定位。

## 三档表

| 档位 | 怎么认 | 后面怎么走 |
| --- | --- | --- |
| 已验证 | 这次实测的那张 8 GB RDNA2 卡（gfx1032），完整配置见 [实测环境](../reference/test-machine.md) | 01 到 07 章按顺序做 |
| 同架构未验证 | 同为 gfx1032 的卡 | 指令集相同，但没有任何执行记录，不继承实测卡的结论 |
| 未验证 | RDNA1/2/3/4 的其他卡、核显（iGPU）、Instinct | 没有记录，既不当成可用，也不当成不可用 |

档位不同，能承诺的范围也不同，逐档解释在 [AMD 显卡适配矩阵](./08-amd-matrix.md)。别急着开始装。

## 三个尺寸的边界

512×512 是主力尺寸。8 GB 这一档先从这里试，这套记录里绝大多数图都在这个尺寸上跑。

768 不是默认值。它只出现在早期基线和个别 Windows 记录里，比如 Qwen Base 的 768 文生图、旧的 768² 16 步基线。想试 768，按个案单独记一次，别直接改默认值。

1024 只在个案里成立。FLUX 1024 采样能跑完，到 CPU 解码时撞上内存保护，把 tile 改成 256、overlap 改成 64 分块解码才拿到图；Kroma 参考链内部升到 1024 时 OOM 了。所以别说「8 GB 这一档能跑 1024」，也别把 1024 当默认尺寸。

## 显存吃紧时

先上分阶段隔离。文本编码、采样、CPU 解码各开一个进程，条件和 latent 通过归档传下去，具体见 [三阶段运行器](../../scripts/run_conditioned_repair.py) 和 [Qwen 参考阶段](../../scripts/run_qwen_reference_repair.py)。CPU VAE 默认打开（[start_ubuntu.sh](../../scripts/start_ubuntu.sh) 里的 `--cpu-vae`），拿时间换显存。

连续生成不要一次排太多。Z-Image 在同一个进程里连出三张已经验证过；Qwen pinned 第一次完整加载跑了十多分钟没完成，这时先停掉，分两批跑。单次成功说明不了长期稳定。

## 这份教程不覆盖的部分

- 别的显卡：只在 [AMD 显卡适配矩阵](./08-amd-matrix.md) 里分「已验证 / 同架构未验证 / 未验证」三档，没测过的卡不做兼容承诺。
- 别的模型权重：只测了 7 个模型系列，权重都钉在具体 revision 上。换量化版本或换权重，都是新实验。
- 画质上限：没做过最高质量参数搜索。512 到 768 是证据范围，不是推荐画质。
- 性能排名：平台、编译、驱动和缓存状态都没统一，文里的秒数不能横向比。
- 陌生机器上的全新安装验收：Windows 的从零步骤是整理出来的复现路径，完整安装还等着补齐；Ubuntu 有安装器，同样只在实测机器上验过。

## 证据与出处

本次实测的机器配置、平台覆盖和版本记录在 [实测环境](../reference/test-machine.md)。

## 和你看到的不一样时

- 不知道自己卡的代号：装好驱动后跑 `rocminfo | grep gfx`，完整做法见 [AMD 显卡适配矩阵](./08-amd-matrix.md)。
- 版本对不上：以 [实测环境](../reference/test-machine.md) 里记的提交和版本为准，或者把差异单独记一次，别在旧结论上接着跑。
- 显卡不是这次实测的那张卡：直接读上面那张三档表，再到 08 章确认。
- 想知道某个数字是怎么来的：翻 [实测环境](../reference/test-machine.md)。

## 过关条件

三条都能答上来，这一章就过了。

1. 你知道自己的机器落在三档里的哪一档。
2. 你知道 512×512、768、1024 三个尺寸各自能试到什么程度。
3. 你知道下一步该走哪一章、为什么。

三条都对上，就可以装环境了。Windows 走 [Windows 环境搭建](./02-windows-setup.md)，Linux 走 [Ubuntu + ROCm](./03-ubuntu-rocm.md)。装完用 [第一张图](./04-first-image.md) 验一次，再按需读 [模型选择](./05-models.md)、[工作流库](./06-workflows.md) 和 [排障](./07-troubleshooting.md)。
