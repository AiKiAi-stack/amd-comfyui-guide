  1. 打开 本机 ComfyUI，展开左侧“工作流”，刷新后进入 模型功能库 / 模型 / 功能。也可下载按钮提供的 UI JSON，通过“打开工作流”载入。

  4. 输入图片内容不变，已用统一文件名整理到包内并补齐本机 input；原路径映射可追溯。不会覆盖不同内容的现有文件，也不自动下载模型。缺少节点、权重或准确配方时明确标阻塞。
