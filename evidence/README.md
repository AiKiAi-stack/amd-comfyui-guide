# 证据目录

本目录保留[功能报告](../report/index.html)引用、以及脚本与测试复查所需的原始证据：逐功能 case、JSON 记录、图片与工作流归档。

- `2026-10-19-features/`：主报告、平台对照数据与 case 记录
- `2026-10-2x-*`：各轮实验的公开证据（报告引用部分）
- `report-assets/`：报告引用的真实出图、输入素材与旧基线 recipe（原 `ComfyUI/input`、`ComfyUI/output` 与根目录 recipe JSON）

报告未引用的原始实验已归档到独立仓库 **[barely-comfy-evidence](https://github.com/AiKiAi-stack/barely-comfy-evidence)**（665 个文件，附 SHA256 清单），按原路径存放，可随时核对或取回；主仓库因此保持轻量。

证据规则与图片去元数据说明见 [reference/evidence-and-privacy.md](../docs/reference/evidence-and-privacy.md)。
